## Các Thành phần Chính

### 1. **Frontend Layer**
- **Next.js Application**: Giao diện người dùng
- **React Context**: Quản lý state toàn cục
- **Web3 Hooks**: Kết nối với blockchain
- **UI Components**: Các component giao diện

### 2. **Blockchain Layer**
- **Core Contracts**: LendingPool, InterestRateModel, PriceOracle
- **Token Contracts**: WETH, DAI, USDC, LINK
- **Library Contracts**: LendingMath, ReserveUserModels
- **Interface Contracts**: IPriceOracle, IInterestRateModel

### 3. **Backend Layer**
- **Indexer Service**: Lắng nghe events và lưu trữ dữ liệu
- **MongoDB Database**: Lưu trữ transaction history
- **API Routes**: Cung cấp dữ liệu cho frontend
- **Oracle Services**: Chainlink nodes và price feeds

### 4. **Infrastructure**
- **Ganache**: Local blockchain cho testing
- **Hardhat**: Development framework
- **Docker**: Containerization
- **Vercel**: Frontend deployment
- **GitHub**: Version control

## Đặc điểm Kiến trúc

1. **Modular Design**: Các contract có trách nhiệm riêng biệt
2. **Interface-based**: Sử dụng interfaces để tương tác
3. **Event-driven**: Sử dụng events để tracking
4. **Oracle Integration**: Hỗ trợ cả manual và Chainlink oracles
5. **Scalable**: Có thể mở rộng thêm assets và features
6. **Secure**: Sử dụng OpenZeppelin libraries và best practices

## Luồng Dữ liệu

1. **User Action** → Frontend → Web3 Wallet → Blockchain
2. **Contract Event** → Indexer → MongoDB → API → Frontend
3. **Price Update** → Oracle → Contract → Frontend
4. **Transaction** → Blockchain → Indexer → Database

Hệ thống được thiết kế theo kiến trúc microservices với các thành phần độc lập, dễ bảo trì và mở rộng.
